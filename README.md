# ViajaMás - Plataforma de Turismo Interactiva

## Descripción

**ViajaMás** es una plataforma web que permite a los usuarios explorar diferentes destinos, recibir recomendaciones de viaje y compartir experiencias. El proyecto incluye información sobre destinos turísticos, comentarios de usuarios.

## Tecnologías Utilizadas

- **Front-End:** HTML5, CSS3, JavaScript
- **Back-End:** Node.js con Express
- **Base de Datos:** MongoDB

## Estructura de Archivos

- `index.html`: Página principal de la web.
- `estilos.css`: Estilos CSS.
- `backend/server.js`: Código del servidor con Node.js.
- `imagenes/`: Carpeta de imágenes.
- `js/javascript.js`: Lógica de JavaScript.
- `pages/`: Otras páginas como "Sobre Nosotros" o "Destinos".

## Funcionalidades

- **Explorar destinos:** Información sobre destinos con descripción, moneda e idioma.
- **Comentarios:** Los usuarios pueden dejar sus experiencias.
- **Filtros:** Búsqueda por países.
- **Registro/Iniciar sesión:** Los usuarios pueden crear una cuenta o iniciar sesión.
