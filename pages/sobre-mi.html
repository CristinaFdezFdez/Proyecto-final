Hola, soy Cristina Fernández

Soy estudiante de Desarrollo de Aplicaciones Web y he creado ViajaMás como proyecto final para demostrar la integración completa entre frontend, backend, base de datos, autenticación y servicios externos.

Ver portfolio Ver GitHub Volver a ViajaMás

Qué es ViajaMás

ViajaMás es una aplicación web full-stack pensada para descubrir destinos, compartir experiencias con fotos, consultar divisas y comunicarse mediante chat en tiempo real.

Tecnologías usadas

  • HTML5, CSS3 y JavaScript
  • React + Vite
  • Node.js + Express
  • MongoDB
  • JWT + bcrypt
  • Socket.io y Cloudinary

Qué he aprendido

Durante el desarrollo he trabajado autenticación segura, subida de imágenes, consumo de APIs externas, comunicación en tiempo real, validaciones, organización MVC y documentación técnica del proyecto.

ViajaMás

ViajaMás es una plataforma creada para inspirar a viajeros, descubrir destinos increíbles y conectar experiencias de todo el mundo. Explora, aprende y comparte tu aventura.
